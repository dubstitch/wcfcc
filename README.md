# WCFCC | Football and Cheer Website

An archived, multi-page front-end website build for the Washington County Football Combine Camp. The original project did not proceed to completion as an active service. This repository preserves the designed experience as a portfolio demonstration.

**Portfolio demo:** https://dubstitch.github.io/wcfcc/

## What is included

- Separate football and cheer experiences with shared navigation and brand styling
- Program details, schedules, coaches, FAQs, registration interface and supporting pages
- Responsive layouts, carousels, accordions, tabs and a sticky ticker
- HTML, CSS and vanilla JavaScript, without a build step

## Archive behavior

The site is **not accepting registrations or messages**. An archive notice appears on the published pages. External links, including Google registration forms, email actions and phone actions, are intentionally locked and visibly marked with a lock symbol. The contact form is disabled. Internal navigation and demonstration interactions remain available.

The historical dates, program details and price are retained as context for the design project, not as current offers. The archive stylesheet is `css/archive.css`, and the shared archive behavior is in `js/site.js`.

## Structure

- `index.html`: primary homepage
- `pages/`: informational and program pages
- `css/site.css`: shared original visual system
- `css/archive.css`: portfolio archive treatment
- `js/site.js`: shared site behavior and archive safeguards

## Notes

This repository represents the original front-end work, not the unrelated website currently operated at the camp's branded domain. No active registration, payment processing or backend service is supplied by this demo.
